## Описание проекта

**MyGemini** — это асинхронный, многоязычный Telegram-бот, который служит вашим личным и безопасным шлюзом к возможностям Google Gemini API. В отличие от публичных ботов, MyGemini использует **ваш собственный API-ключ**, что обеспечивает вам полный контроль над квотами и расходами.

Бот спроектирован с акцентом на приватность и гибкость. Вы можете вести **несколько независимых диалогов** одновременно, чтобы контексты разных задач не смешивались. А благодаря системе **"персон"**, вы можете превратить бота из обычного ассистента в профильного эксперта: программиста, финансового советника или историка.

## 🚀 Основные возможности

### Для пользователей

*   **Персональный API-ключ:** Работает с вашим личным ключом Google AI, обеспечивая приватность и контроль над использованием API.
*   **Безопасное хранение:** API-ключи пользователей надежно шифруются перед сохранением в базу данных.
*   **Многоконтекстные диалоги:** Создавайте, переключайтесь, переименовывайте и удаляйте независимые диалоги, чтобы контексты разных тем не пересекались.
*   **Гибкая персонализация:**
    *   **Выбор "персоны":** Задайте боту роль (например, "Эксперт по Python", "Копирайтер"), и он будет отвечать в соответствии с ней.
    *   **Выбор модели:** Переключайтесь между быстрой `gemini-1.5-flash` и мощной `gemini-1.5-pro` в зависимости от задачи.
    *   **Смена языка:** Интерфейс бота поддерживает русский и английский языки.
*   **Интеллектуальное общение:** Ответы на вопросы и генерация текста на основе модели Google Gemini с учетом выбранной персоны и истории диалога.
*   **Анализ изображений:** Распознавание и описание содержимого изображений с возможностью задать уточняющий вопрос.
*   **Поиск в интернете:** Для предоставления актуальной информации бот может обращаться к поиску Google. Эта функция активируется автоматически, если выбранная модель ее поддерживает. На данный момент поиск доступен для моделей: `gemini-2.0-flash`, `gemini-2.5-flash`, `gemini-2.0-pro-experimental` и `gemini-2.5-pro`.
*   **Подробная справка:** Встроенное руководство (`/help_guide`) поможет новым пользователям быстро освоиться, включая пошаговую инструкцию по получению API-ключа.
*   **Личный кабинет и статистика:**
    *   `/account`: Просматривайте свой "титул" в боте, общую статистику и краткий анализ тем в текущем диалоге.
    *   `/usage`: Отслеживайте статистику использования токенов и примерную стоимость запросов.

### 👑 Для администратора

Бот включает в себя мощную админ-панель (`/admin`) для полного контроля над его работой:

*   **Глобальная статистика:** Просмотр общего числа пользователей, активности за последние 7 дней и количества заблокированных.
*   **Управление пользователями:**
    *   Поиск пользователя по ID для просмотра детальной информации (дата регистрации, язык, статус).
    *   Блокировка и разблокировка пользователей.
    *   Принудительный сброс API-ключа пользователя в случае компрометации.
*   **Коммуникация:**
    *   **Массовая рассылка:** Отправка сообщений всем пользователям бота.
    *   **Индивидуальные сообщения:** Отправка личного сообщения любому пользователю через интерактивное меню или с помощью команды `/reply`.
*   **Экспорт данных:** Выгрузка списка всех пользователей в `.csv` файл.
*   **Режим обслуживания:** Временное отключение бота для всех, кроме администратора, на время проведения работ.

## Технологии

*   **Python 3.10+:** Основной язык программирования.
*   **pyTelegramBotAPI (async):** Асинхронная библиотека для работы с Telegram Bot API.
*   **aiohttp:** Для выполнения прямых, неблокирующих HTTP-запросов к Gemini API.
*   **Cryptography:** Для надежного шифрования API-ключей пользователей.
*   **python-dotenv:** Для управления конфигурацией через `.env` файлы.
*   **PyYAML:** Для конфигурации системы логирования.
*   **sqlite3:** Встроенная база данных SQLite для хранения пользовательских данных и истории сообщений.
*   **Pillow:** Для обработки изображений перед отправкой в API.
*   **cachetools:** Для LRU-кэширования истории диалогов и предотвращения утечек памяти.
*   **LangChain:** Для надежного семантического разделения длинных текстов на фрагменты, сохраняя структуру Markdown.
*   **telegramify-markdown:** Для корректного преобразования Markdown в формат Telegram MarkdownV2 с экранированием всех спецсимволов.

## Настройка и запуск

### Предварительные требования

*   **Python 3.10 или выше.**
*   **pip:** Менеджер пакетов Python.
*   **Git:** Для клонирования репозитория.

### Шаги по установке

1.  **Клонируйте репозиторий:**
    ```bash
    git clone [https://github.com/kobaltgit/MyGemini]
    cd MyGemini
    ```

2.  **Создайте и активируйте виртуальное окружение (рекомендуется):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # для Linux/macOS
    # или
    venv\Scripts\activate  # для Windows
    ```

3.  **Установите зависимости проекта:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Сгенерируйте ключ шифрования:**
    В репозитории уже есть утилита `generate_key.py`. Выполните её для получения секретного ключа:
    ```bash
    python generate_key.py
    ```
    Скопируйте полученную строку (`ENCRYPTION_KEY=...`) в ваш `.env` файл.

5.  **Настройте переменные окружения:**
    Создайте файл `.env` в корневой директории проекта и добавьте в него следующие переменные:

    ```env
    # Токен вашего Telegram-бота от @BotFather
    BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11

    # Ваш Telegram User ID для админских уведомлений (опционально)
    ADMIN_USER_ID=123456789

    # Ключ шифрования, который вы сгенерировали на предыдущем шаге
    ENCRYPTION_KEY=..._ваша_сгенерированная_строка_...

    # Модель Gemini, которую будет использовать бот по умолчанию (опционально)
    DEFAULT_MODEL_ID=gemini-2.5-flash

    # Старое имя переменной тоже поддерживается для обратной совместимости
    # GEMINI_MODEL_NAME=gemini-1.5-flash-latest

    # Ссылка для донатов (опционально, если хотите добавить кнопку "Поддержать")
    DONATION_URL=https://pay.example.com/your_donation_page
    ```

### Запуск бота

Запустите бота, выполнив следующую команду в терминале:

```bash
python main.py
```

После запуска бот готов к работе. Найдите его в Telegram и отправьте команду /start.

## Первое использование
1. При первом запуске бот попросит вас установить API-ключ.
2. Используйте команду `/set_api_key`.
3. Отправьте боту ваш API-ключ от [Google AI Studio](https://makersuite.google.com/app/apikey).
4. После успешной установки ключа вы сможете полноценно пользоваться ботом.

## Основные команды
*   `/start` - Перезапустить бота.
*   `/help_guide` - Показать полное руководство по всем функциям бота.
*   `/apikey_info` - Показать инструкцию по получению API-ключа.
*   `/dialogs` - Открыть меню управления диалогами.
*   `/settings` - Открыть меню настроек (выбор персоны, модели, языка).
*   `/usage` - Показать статистику расходов токенов.
*   `/account` - Открыть личный кабинет.
*   `/history` - Посмотреть историю сообщений в текущем диалоге.
*   `/reset` - Создать новый пустой диалог и начать с чистого контекста.

## Структура директорий
```
MyGemini/
├── .env                    # Файл с переменными окружения (секреты, токены). Создается вручную.
├── logger_config.py        # Настройка и конфигурация системы логирования.
├── main.py                 # Основной файл для запуска бота, инициализация и запуск polling'а.
├── readme.md               # Этот файл. Документация по проекту.
├── requirements.txt        # Список внешних библиотек и зависимостей проекта.
│
├── config/
│   ├── logging.yaml        # YAML-конфигурация для логгера (форматтеры, обработчики, уровни).
│   └── settings.py         # Загрузка переменных окружения и определение глобальных констант.
│
├── database/
│   ├── db_manager.py       # Менеджер базы данных. Содержит все функции для работы с SQLite.
│   └── bot_database.db     # Файл базы данных SQLite (создается автоматически).
│
├── features/
│   └── personal_account.py # Логика для формирования страницы 'Личный кабинет' (/account).
│
├── guides/
│   ├── full_guide_ru.md    # Полная справка по боту на русском языке.
│   └── full_guide_en.md    # Полная справка по боту на английском языке.
│
├── handlers/
│   ├── admin_handlers.py     # Обработчики команд и callback-запросов для админ-панели.
│   ├── callback_handlers.py  # Обработчики всех callback-запросов от inline-кнопок (кроме админских).
│   ├── command_handlers.py   # Обработчики команд-сообщений (/start, /help, /settings и т.д.).
│   ├── decorators.py         # Декораторы, используемые в обработчиках (например, @admin_required).
│   ├── message_handlers.py   # Универсальный обработчик для всех входящих сообщений, маршрутизация по состояниям.
│   └── telegram_helpers.py   # Вспомогательные функции для работы с Telegram API (отправка, редактирование сообщений).
│
├── logs/                   # Директория для файлов логов (создается автоматически).
│
├── services/
│   ├── error_parser.py     # Парсер ошибок Gemini API для преобразования их в понятные пользователю сообщения.
│   └── gemini_service.py     # Сервис для взаимодействия с Google Gemini API (отправка запросов, управление историей).
│
└── utils/
    ├── analysis_helpers.py   # Функции для анализа текста (извлечение тем из истории диалога).
    ├── crypto_helpers.py     # Функции для шифрования и дешифрования данных (API-ключей).
    ├── guide_manager.py      # Менеджер для загрузки и предоставления текстов справки из файлов.
    ├── localization.py       # Модуль локализации. Содержит все тексты интерфейса на разных языках.
    ├── markup_helpers.py     # Функции для создания всех клавиатур (reply и inline) в боте.
    └── text_helpers.py       # Вспомогательные функции для обработки текста (очистка от Markdown и т.д.).
```

## Система логирования 
огирование настроено через файл `config/logging.yaml`. Логи разделены по файлам и сохраняются в директорию `logs/`:

*   **bot_general.log** - общие логи работы приложения.
*   **database.log** - логи, связанные с операциями базы данных.
*   **gemini_api.log** - логи запросов к Gemini API.
*   **user_messages.log** - логи входящих сообщений от пользователей.
