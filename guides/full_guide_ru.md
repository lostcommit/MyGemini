# [НАЧАЛО РАЗДЕЛА: API_KEY]

### 🔑 Как выбрать backend и установить API-ключ

Бот поддерживает два backend'а: **Google Gemini** и **OpenAI**.

API-ключ — это ваш персональный доступ к выбранному AI-сервису. Бот шифрует и хранит ключ, не передавая его третьим лицам.

#### Пошагово

1. **Откройте `/settings`** и выберите backend:
   * `Google Gemini`
   * `OpenAI`

2. **Отправьте команду `/set_api_key`**.

3. **Отправьте ключ для текущего backend**:
   * Для Gemini: ключ из [Google AI Studio](https://makersuite.google.com/app/apikey)
   * Для OpenAI: ключ из вашего аккаунта OpenAI

4. После проверки ключа бот сохранит его и позволит выбрать модель в `/settings`.

#### Если вы используете Gemini

1. Перейдите в [Google AI Studio](https://makersuite.google.com/app).
2. Откройте раздел **Get API key**.
3. Создайте ключ и скопируйте его.
4. Вернитесь в бот и отправьте его через `/set_api_key`.

#### Если вы используете OpenAI

1. Откройте ваш кабинет OpenAI.
2. Создайте новый API key.
3. Скопируйте ключ.
4. Вернитесь в бот и отправьте его через `/set_api_key`.

# [НАЧАЛО РАЗДЕЛА: FEATURES]

### 🚀 Возможности бота

После установки API-ключа вам становятся доступны следующие функции:

#### 🧠 Основной чат
Просто пишите свои вопросы или задания в чат. Бот поддерживает контекст беседы в рамках активного диалога.

#### 🖼️ Анализ изображений
Отправьте боту картинку как фото. Анализ изображений поддерживается и для Gemini, и для OpenAI.

#### 🗂️ Управление диалогами (`/dialogs`)
Бот позволяет вести несколько независимых бесед одновременно.
* **Создание:** Нажмите «➕ Создать новый».
* **Переключение:** Нажмите на название диалога.
* **Переименование:** Используйте кнопку «✏️».
* **Удаление:** Используйте кнопку «❌» у неактивного диалога.

#### 📜 История сообщений (`/history`)
Можно посмотреть переписку по текущему активному диалогу за выбранную дату.

#### 📊 Статистика расходов (`/usage`)
Показывает количество токенов за сегодня и за месяц, активный backend, текущую модель и примерную стоимость там, где pricing настроен.

#### 👤 Личный кабинет (`/account`)
Показывает ваш профиль, активный backend, текущую модель, число сообщений и краткий анализ тем текущего диалога.

#### 🎙️ Голосовые сообщения
* Для Gemini: поддерживаются.
* Для OpenAI: пока не поддерживаются.

# [НАЧАЛО РАЗДЕЛА: SETTINGS]

### ⚙️ Настройки (`/settings`)

В этом меню можно настроить поведение бота.

#### 🧠 Backend
Сначала выберите, через какой backend бот будет отвечать:
* `Google Gemini`
* `OpenAI`

#### 🤖 Модель
После выбора backend и установки API-ключа можно выбрать модель, доступную для этого backend.

#### 🎭 Персона
Персона задаёт роль ассистента: например, эксперт по Python, историк, копирайтер и т.д.

#### 👔 Стиль общения
Работает для обычного ассистента и задаёт общий тон ответов.

#### 🌐 Язык интерфейса
Переключает язык кнопок и системных сообщений между русским и английским.
